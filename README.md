# Photos

A modern, high-performance photo gallery, organizer, and non-destructive image editor.

## Features

- **Dynamic Gallery Views**: Responsive Masonry layout, square grid, and detailed metadata list view.
- **Album & Geography Management**: Create and manage albums, cluster photos by shooting locations and countries.
- **EXIF & Metadata Inspector**: View detailed camera models, lens optics, aperture, shutter speed, ISO, focal length, file sizes, and resolutions.
- **In-Browser Image Editor**: Canvas-based real-time adjustments for brightness, contrast, saturation, warmth, sepia, black & white, vignette, and rotation, with instant JPEG export download.
- **Search & Filter**: Search by title, tags, location, or camera gear, plus category pill filters and 1-5 star ratings.
- **Photo Ingestion**: Drag-and-drop or manual upload with automated aspect ratio and dimension calculation.
- **Persistence**: Local caching ensures albums, uploads, adjustments, and favorites are preserved across sessions.
